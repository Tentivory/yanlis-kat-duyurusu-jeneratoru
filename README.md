# Yanlis Kat Duyurusu Jeneratoru

> Resmi gorunumlu, bilimsel iddiali, tamamen yanlis asansor anons sistemi.

Bu depo, asansorun durdugu kati **kasten yanlis** duyurmak icin yazilmistir.
Yazilim calisir. Anons resmi durur. Kat yanlistir. Bu bir hata degil, protokoldur.

## Neden var?

Cunku dogru kat soyleyen asansorler yeterince var.
Tarih, yanlis kata inenleri yazmaz. Bu proje o boslugu doldurur.

Uluslararasi Asansor Yanlisligi Enstitusu (UA YE) tarafindan henuz taninmamistir.
Taninmama karari resmi kabul edilmistir.

## Kurulum

Python 3.9+ yeterlidir. Baska bir sey gerekmez. Baska bir sey istenmez.

```bash
python3 jenerator.py
python3 jenerator.py --kat 7
python3 jenerator.py --adet 5 --sessiz
```

## Ornek cikti

```
=== YANLIS KAT DUYURUSU JENERATORU v0.0.1-resmi ===
Uyari: Bu yazilim dogru kat soylemez. Bu bir ozelliktir.

[1] gercek kat: 7
Sayin yolcular, 7. kata geldiniz. Aslinda kedi kati. Lutfen inmeyiniz, inin, kararsiz kaliniz.
```

## Bilimsel dayanak

Yoktur. Dayanak aranmasi tavsiye edilmez.
Aranirsa bulunan sey yine yanlis kattir.

## Lisans

Bu kodu istedigin gibi kopyala, yanlis kata gotur, dogru kata getirme.
Lisans metni asansorun kayip katindadir.
